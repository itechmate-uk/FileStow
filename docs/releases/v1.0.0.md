FileStow 1.0.0: server file and database backups with rclone, a resource-aware
watchdog, and a browser GUI that installs, configures and updates it.

- **Backups.** Folders (each project on its own, so one failure never stops the
  others) and databases, to any rclone destination: Google Drive, Dropbox, OneDrive,
  S3 and compatible stores, Backblaze B2, WebDAV, SFTP and more. Replaced and deleted
  files are kept in an archive folder for as long as you choose.
- **Gentle on the server.** Resource profiles (slow, moderate, fast; fixed or
  adaptive) and a watchdog that contains, pauses or stops a backup before it can
  starve the server, with ntfy notifications.
- **GUI.** Runs as your login (or one system-wide GUI), reached through an SSH
  tunnel: jobs, destinations, folder picker, every setting, runs, logs and audit.
- **Updates from the GUI.** The top-bar button shows when a release is out; Update
  everything updates FileStow and the GUI, checked against the release's SHA-256.

Install: download `filestow-1.0.0.tar.gz` and its `.sha256` from this release, then

```bash
sha256sum -c filestow-1.0.0.tar.gz.sha256
tar -xzf filestow-1.0.0.tar.gz
sudo filestow-1.0.0/install.sh --install-deps
```

See [docs/INSTALLATION.md](https://github.com/itechmate-uk/FileStow/blob/v1.0.0/docs/INSTALLATION.md)
