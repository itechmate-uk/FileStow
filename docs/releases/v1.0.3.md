FileStow 1.0.3: database backups after an upgrade, and the Updates window.

- **Database backups.** An upgrade now also re-installs `database-backup.service` and
  `database-size-check.service` from the new release (with a rollback copy). Before,
  they kept the paths of the first install, so after the move from Backup Suite they
  failed with exit code 203 ("program not found") and their failure notice could not
  be sent. Updating to 1.0.3 repairs them; they run again at their next scheduled time.
- **Updates window.** The Installer log and Release notes stay open, and keep their
  scroll position, while the window refreshes; only their text is updated.
