FileStow 1.0.1: fixes.

- **GUI updates.** A GUI installed by `sudo ./install.sh` now gets its updater. In
  1.0.0 it was left out, so the Updates window said "This GUI has no updater yet". If
  your GUI says that, install the GUI once more from this release, as your login and
  without sudo: `./install.sh --gui-only`. From then on it updates itself.
- The Updates window, the Logs view and a job's Log tab no longer show a stray "null".
- The last two places that still said "Backup Suite" (CONTRIBUTING.md and an example
  policy file) now say FileStow.
