Backup Suite 1.1.6: the project now lives at https://github.com/itechmate-uk/FileStow.

- Updates (from the GUI and from `backup-suite-update.py`) now come from the
  FileStow repository's releases. The download and SHA-256 checks are unchanged.
- Links in the GUI, the systemd units, the docs and NOTICE point to the new repository.
- Nothing else changes: configuration, credentials, jobs and the resource setup are kept.

An install older than 1.1.6 still looks for updates in the old repository, which is
no longer public. Install 1.1.6 on it once by hand (see docs/INSTALLATION.md);
from then on it updates itself from FileStow.
